# Page Pulse Client

Next.js frontend for the Page Pulse URL audit service.

## Run Locally

```bash
npm install
npm run dev
```

Create `.env.local`:

```bash
NEXT_PUBLIC_API_URL=http://localhost:3000
```

The footer includes the required Digital Heroes task credit.

## Scripts

- `npm run dev` - start the local Next.js dev server
- `npm run lint` - run ESLint
- `npm run build` - create a production build
